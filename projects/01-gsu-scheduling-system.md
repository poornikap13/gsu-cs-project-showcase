# GSU Scheduling System

**Institution:** Governors State University
**Category:** Computer Science Student Capstone Project
**Tech Stack:** Java, Spring Boot, MySQL, Bootstrap
**Year:** 2025

## Project Overview
A full-stack academic scheduling application designed to manage course registrations, instructor availability, and room assignments for university departments. 

## Key Features
- **Conflict Detection:** Prevents two classes from being scheduled in the same room at the same time.
- **Instructor Availability Tracking:** Allows professors to input their preferred teaching hours.
- **Automated Waitlist Management:** Automatically promotes students from the waitlist when a spot opens.
- **Admin Dashboard:** Provides department heads with a real-time overview of all scheduled classes.

## Why It Matters
This project demonstrates GSU students' ability to build production-grade, database-driven applications using enterprise-level Java frameworks. It mimics the software used by university registrars across the country.
