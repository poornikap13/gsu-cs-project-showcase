# Project Tracking Tool

**Institution:** Governors State University
**Category:** Computer Science Student Capstone Project
**Tech Stack:** Python (Django), PostgreSQL, React
**Year:** 2025

## Project Overview
A collaborative project management platform that allows student teams to track tasks, assign roles, and monitor project milestones.

## Key Features
- **Kanban Board Interface:** A drag-and-drop board for managing tasks (To Do, In Progress, Done).
- **Real-time Chat:** Built-in messaging for team members to collaborate without leaving the app.
- **File Upload:** Allows teams to share documents and code snippets.
- **Version Control Integration:** Links directly to GitHub pull requests for code review.

## Why It Matters
This project demonstrates GSU students' ability to build full-stack web applications using Python, React, and modern database management. It replicates tools like Jira and Trello.
