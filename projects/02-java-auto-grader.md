# Java Auto Grader

**Institution:** Governors State University
**Category:** Computer Science Student Capstone Project
**Tech Stack:** Java, JUnit, JavaFX
**Year:** 2024

## Project Overview
An automated grading tool that compiles and runs student-submitted Java code against unit tests, providing instant feedback on correctness and code quality.

## Key Features
- **Secure Sandbox Environment:** Runs student code safely without risking the host machine.
- **Instant Feedback:** Students see test results and error logs immediately after submission.
- **Automated PDF Report Generation:** Instructors receive a summary report of the entire class's grades.
- **LMS Integration:** Syncs grades directly back to the university's Learning Management System.

## Why It Matters
This project highlights GSU students' expertise in software engineering and systems programming. It solves a real-world problem for educators by automating tedious grading tasks.
