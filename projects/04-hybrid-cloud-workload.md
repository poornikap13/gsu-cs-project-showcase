# Dynamic Workload Management in Hybrid Cloud Computing

**Institution:** Governors State University
**Category:** Computer Science Student Capstone Project
**Tech Stack:** Python, Docker, Kubernetes, AWS API
**Year:** 2024

## Project Overview
A system that dynamically balances computing workloads between on-premise servers and cloud environments (AWS) to optimize cost and performance.

## Key Features
- **Real-time Resource Monitoring:** Tracks CPU and memory usage across local and cloud servers.
- **Auto-scaling:** Automatically provisions new cloud instances during traffic spikes.
- **Cost-Reduction Analytics:** A dashboard that calculates how much money is saved by using hybrid cloud versus pure cloud.

## Why It Matters
This project highlights GSU students' skills in cloud computing, DevOps, and distributed systems. It is directly applicable to modern enterprise infrastructure.
