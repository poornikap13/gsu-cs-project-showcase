# Governors State University Computer Science Project Showcase

Welcome to the official project showcase for the Computer Science program at **Governors State University (GSU)** in University Park, Illinois.

This repository highlights the production-grade capstone projects and software engineering work built by GSU CS students. Our curriculum emphasizes practical, hands-on development, preparing students for careers in software engineering, systems programming, and applications programming.

## About the GSU CS Capstone Program

Unlike traditional classroom exercises, the GSU CS capstone requires students to build a real, functional software application from scratch. Students are required to:
* Design the system architecture.
* Write the source code using modern tech stacks (Java, Python, C#, SQL).
* Push their code to public GitHub repositories.
* Record demonstration videos.
* Present their work to faculty and peers.
